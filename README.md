# 🪟 Evolução do Sistema Operacional Windows

Repositório destinado à pesquisa histórica das versões do Microsoft Windows, realizado para a disciplina de [Nome da Disciplina].

## 📜 Linha do Tempo

| Versão | Ano | Principal Novidade | Curiosidade |
| :--- | :---: | :--- | :--- |
| **Windows 1.0** | 1985 | Interface gráfica sobre o MS-DOS. | O nome original do projeto era "Interface Manager". |
| **Windows 3.x** | 1990 | Gerenciador de Programas e suporte a 256 cores. | Foi a versão que popularizou o jogo *Paciência* para ensinar o uso do mouse. |
| **Windows 95** | 1995 | Menu Iniciar e Barra de Tarefas. | A Microsoft pagou milhões para usar a música "Start Me Up" dos Rolling Stones no comercial. |
| **Windows 98** | 1998 | Introduziu recursos como Internet Explorer 4.0 |O sistema trazia o Active Desktop, que permitia colocar conteúdos da internet, como notícias e ações, diretamente na área de trabalho. |
| **Windows ME** | 2000 | Introduziu o Windows Movie Maker, restauração do sistema (System Restore) e atualizações automáticas | O sistema travava com tanta frequência que usuários começaram a chamá-lo de "Mistake Edition" ou "Mistake Edition"|
| **Windows 2000** | 2000 |  Introduziu o Encrypting File System (EFS) para segurança de arquivos e o Windows File Protection (WFP) para proteger arquivos do sistema |Introduziu o Active Directory e foi base para o sistema operacional do Xbox original e Xbox 360. |
| **Windows XP** | 2001 | Estabilidade (Kernel NT) e novo visual "Luna". | A famosa imagem do papel de parede (Bliss) é uma foto real, sem Photoshop. |
| **Windows Vista** | 2007 | Interface Aero: Introduziu transparências, animações e o "Flip 3D" (Windows + Tab). |Interface Aero Glass: Introduziu um visual translúcido, moderno e elegante que exigia placas de vídeo potentes, tornando o sistema lento em computadores antigos.|
| **Windows 7** | 2009 | Introduziu recursos como Aero Snap, Aero Shake, e melhor compatibilidade com drivers, sendo muito utilizado para jogos na época. |Pela primeira vez, os ícones ficaram maiores, permitindo fixar programas e visualizar prévias de janelas abertas. |
| **Windows 8** | 2012 |introduzindo a interface "Metro" (ou Modern UI) com blocos dinâmicos e removendo o menu Iniciar tradicional. |Senha por Imagem: Uma curiosidade divertida era a possibilidade de desenhar círculos, toques ou linhas sobre uma foto para fazer o login, em vez de digitar uma senha. |
| **Windows 10** | 2015 |  focado em versatilidade para desktops e dispositivos touch. | Reintroduziu o menu Iniciar convencional, combinando elementos do Windows 7 e 8, funcionando bem em diversas plataformas |
| **Windows 11** | 2021 | Menu Iniciar centralizado e suporte a apps Android. | É a primeira versão que exige obrigatoriamente o chip de segurança TPM 2.0. |
